Type with your voice, anywhere on your Mac.

Tap a hotkey, speak English or German and insert the transcript where you type. Useful Voice also keeps searchable notes and a personal dictionary.

A Useful Build product. Notes and history stay on your Mac. Audio and dictionary hints go to Deepgram for transcription.

View source and setup See the app

macOS 14+ · Apple Silicon · Build from source · Deepgram API key required

Dictate

Tap Right Command once to start and again to stop. The words appear where you are typing.

Notes

Write or dictate a note. Search it later, or append the latest transcript.

Dictionary

Add names and specialist terms as transcription hints. Review the result, especially for unfamiliar words.

Settings

Language, hotkey and Deepgram. The API key stays in the macOS Keychain.

Build Useful Voice for your Mac.

Available from source for Apple Silicon Macs running macOS 14 or later. Setup requires Xcode command-line tools and your own Deepgram API key. Deepgram usage is billed separately. Follow the repository instructions to build the app.
